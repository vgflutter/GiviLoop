# GiviLoop 0.5.0

Get to a first review with guided setup, then preserve why advice was accepted or rejected. This release adds onboarding and evidence recording to the existing CLI/MCP workflow.

- `givi setup` checks prerequisites, offers provider/login/access choices, generates a local MCP configuration snippet and can run an opt-in public example. It does not modify editor settings, install models or choose an implicit provider for later commands.
- `givi findings add|update|list` and `givi_record_finding` / `givi_list_findings` keep claims, confirmed/dismissed/unverified assessments, reasons, evidence, file hashes and decision history. Runs with findings survive automatic retention cleanup.
- Changed referenced files or review content make prior conclusions stale and effectively unverified. Hashes capture files when an assessment is recorded; unreferenced context/environment changes are not detected.
- `givi recheck` / `givi_prepare_recheck` create a new request for one finding with current source and parent links. Inspect it and explicitly send it; no automatic submission, patch execution or fixed verdict.
- A new video shows real setup, a live Claude review, independent example assertions, evidence recorded through MCP and a targeted recheck. The dismissed false claim is an **author-supplied control**, not a claim attributed to Claude. Only the temporary demo copy is corrected.

The host user/agent verifies claims. GiviLoop stores that assessment; it does not run or certify evidence, and an empty finding list does not prove clean code. [Setup and evidence guide](../setup-and-evidence.md).

Existing web adapters remain experimental: website changes, authentication, verification and quotas still apply. Headless ChatGPT is unsupported in live checks; use background mode. This release does not establish provider authorization. Avoiding an extra model API call is distinct from unmeasured total token savings. The [0.4.0 provider limits](0.4.0.md) and [cost/access conditions](../costs-and-access.md) still apply.

## Install

Download the attached package, then:

```sh
npm install -g ./giviloop-0.5.0.tgz
givi setup --repo /path/to/project
```

Node.js 20+ is required. Restart existing MCP servers to expose the new tools. GitHub tarball/source distribution only; no npm registry publication.

The attached test report, TAP logs and checksums identify the exact CI-checked package. Validation includes the installed package, CLI/MCP evidence persistence, setup isolation and the browser fixture suite, plus Node 20/22/24 on Linux/macOS. The video uses a real website; automated browser fixtures use isolated synthetic pages.
