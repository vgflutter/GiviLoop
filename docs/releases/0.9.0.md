# GiviLoop 0.9.0

A smaller interface for a second code review, with web reviews that stay out of
your editor's way.

- Eight default MCP tools, including `givi_review` with your saved reviewer and
  `givi_manage_review` for recovery. `--tools full` retains advanced discovery.
- MCP web reviews and resume always use windowless ordinary Chrome. Visible
  overrides and `givi_open` are rejected before sending. Login, verification
  and ZIP uploads pause for manual CLI recovery; no visible fallback opens.
- Short CLI help for setup → review → status → report; `givi help --all` keeps
  the detailed reference. Explicit review IDs still isolate finding updates.
- Windows shutdown fallback targets only the Chrome process tree launched by
  GiviLoop. Release checks cover package installation, browser recovery and
  native desktop observation; deliberately visible tests run only in CI.
- A reproducible token benchmark reports measured agent usage. Avoiding a
  separate review API call does not establish lower total agent tokens or cost.

## Upgrade

Install the attached checked package, then restart/reconnect your MCP client:

```sh
npm install -g ./giviloop-0.9.0.tgz
```

For a source checkout, update to `v0.9.0`, run `npm ci` and `npm run build`.
Existing review ledgers need no migration. Keep each review's `runId` when
recording findings. Old named review tools remain callable, but visible browser
controls are no longer available through MCP. Use the updated
[tool reference](../mcp-tools.md) and [review skill](../../skills/giviloop-review/SKILL.md).

## Scope

Web integrations remain experimental and subject to provider quotas, login,
verification and terms. The checked browser fixtures do not guarantee access to
every live account or website revision. Local reviewers remain available.
See [provider results](../web-providers.md) and [costs/access](../costs-and-access.md).

The HOL Guard contribution is optional and awaiting upstream integration. It
covers six direct CLI operations, not MCP; it is not a released protection layer.
See [the precise scope](../usage.md#short-help-and-hol-guard-scope).

The release attachments include the exact CI-tested installable package,
platform reports, test logs and SHA-256 checksums. Full results are linked from
the GitHub release.
